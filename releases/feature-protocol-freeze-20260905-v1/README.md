# Feature-protocol freeze

The `evidence/` directory is the accepted feature-protocol freeze package. The active
copies of `feature_policy.json`, `label_ontology.json`, and associated decision documents
are also installed at the repository root under `config/` and `docs/`.

This freeze records zero cross-dataset feature admission and preserves the dataset-native
32/39/115-feature mainlines. It is protocol state, not permission to rerun data processing.
